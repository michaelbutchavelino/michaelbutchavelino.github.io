# Michael Butch Avelino — Portfolio Website

This is a simple, responsive portfolio website for Michael Butch Avelino.

## Publish with GitHub Pages (free)

1. Create or sign in to your GitHub account.
2. Create a new **public** repository, for example `michael-avelino-portfolio`.
3. Upload `index.html` and `style.css` from this folder.
4. Open the repository's **Settings → Pages**.
5. Under the publishing/source option, choose **Deploy from a branch**.
6. Select the `main` branch and the `/ (root)` folder, then save.
7. GitHub will provide your public portfolio URL.

Your URL will usually look like:
`https://YOUR-GITHUB-USERNAME.github.io/michael-avelino-portfolio/`

## Before publishing

- Replace the LinkedIn URL if your profile URL has changed.
- You can add a professional photo later if you want.
- The site intentionally does not include sensitive personal information.
